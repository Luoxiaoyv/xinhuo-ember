# 心火 EMBER

**掷骰问命，以火养习**

不打卡 · 不催促 · 不排名

掷骰问命领一张签，做了就烧掉它。
二十一天后，火会给你写一封信。

<sub>单文件 · 零依赖 · 零外链 · 离线可用 · 数据不上传</sub>

</div>

---

## 这是什么

一个把「内驱力」做成游戏的习惯养成应用。

绝大多数习惯 App 的逻辑是：**立目标 → 每日打卡 → 攒积分 → 排行榜**。
它们的前提假设是——你需要被推动。

心火假设相反：**你本来就想要，只是没被看见。**

于是它把整套机制反过来：任务不由你定，由骰子定；不做没有惩罚，只有"化灰"；奖赏不给积分，只给火焰、称号，和月底的一封信。

---

## 和打卡 App 有什么不一样

|              | 常见打卡 App          | 心火 EMBER                          |
| ------------ | --------------------- | ----------------------------------- |
| 任务从哪来   | 你自己立 flag         | **掷骰，命运派签**                  |
| 不做会怎样   | 断签、红点、连续记录碎掉 | **什么都不会发生**，签静静化灰      |
| 奖励是什么   | 积分、商城、排行榜    | 火焰变大、称号解锁、一封月信        |
| 谁在监督你   | 算法、好友、打卡群    | **没有人**                          |
| 数据在哪     | 厂商服务器            | 你自己的浏览器 localStorage         |
| 用到第 21 天 | 换个皮肤继续打卡      | 生成月签，**重铸签池，开新循环**    |

一句话：**它不催你，它只是让你的火被看见。**

## 玩法

### 一 · 点火

留名 + 勾选意向（考证 / 阅读 / 身心 / 技能，可多选）。
意向不设目标，只用来决定签池的偏向——你说你想读点书，命运就更常递书给你。

### 二 · 掷骰问命

点底部「骰」，掷一个 3D 立方体。

- **骰面决定类别**：1–2 成长 · 3–4 修行 · 5–6 天命
- **命运决定内容**：从签池里随机抽一张

手里最多同时留 **3 张签**。

### 三 · 不满意，自己下

抽到的签不合胃口？点「**不满意 · 自拟**」，改名字、换类别、写一句描述。

自己写的签会进 **常用签池**——下次掷骰，命运会优先从**你写过的那堆里**抽。
用得越久，签池越像你。某天你会意识到：这些签已经几乎全是你自己下的了。

到那天，它就该变成真习惯了。

### 四 · 烧签

完成了，点「完成此签」，卡片带着火星焚尽，印记落进图鉴。
不想做，点「释放」——**没有任何惩罚**，也不是失败。

### 五 · 入夜

今天的签处理完，点「入夜」推进一天。
外环 21 个齿，亮一个齿就是那天烧过签。

至少烧一签，火才不会变小。**连燃越久，火越旺。**

### 六 · 二十一天，一封信

满 21 天，自动生成 **月签**——一封根据你这 21 天**真实行为**写下的信：

- 火势判定（火已成势 / 风中之火 / 灰下余温）
- 行为数据解读（完成率、类别偏好、连燃长度、哪天最容易熄）
- 针对你的建议
- 一份意向问卷 → 按你的回答**重铸下月签池**，开启新循环

你写过的每一张签、烧过的每一天，都在里面。

## 奖赏机制：全在精神层

心火**没有**积分、商城、优惠券、排行榜、好友 PK、付费皮肤。

它的奖赏只有四样：

| 奖赏       | 怎么得到                     | 形态                                       |
| ---------- | ---------------------------- | ------------------------------------------ |
| **火**     | 连燃天数增长                 | 焰形随尺度放大，不弹窗、不变黄、不催促     |
| **称号**   | 达成特定行为（如连燃 21 天） | 朱印授勋，一次性，不可重复获得             |
| **印记**   | 每烧掉一张签                 | 落进图鉴，**跨循环永久保留**               |
| **月签**   | 每 21 天                     | 一封只属于你的信，循环结束即封缄           |

设计上刻意做了减法：

- 没有红点、未读、连续签到提醒
- 未完成的签**停留 2 天后自行化灰**，不留痕迹
- 火变大时界面不会"庆祝"——它只是安静地变大了

**内驱力不需要被兑换，它只需要被看见。**

## 快速开始

### 直接玩

下载 `index.html`，双击用浏览器打开即可。手机上打开会自动全屏沉浸。

想装成 App：浏览器菜单里选「**添加到主屏幕**」，它会以全屏应用的形式运行（PWA），断网也能用。

### 本地起个服务（可选，更推荐）

```bash
npm start          # → http://localhost:5173
```

### 跑测试

```bash
npm test           # 或 node test/test.js
```

102 项断言，覆盖「点火 → 掷骰 → 自拟签 → 烧签 → 入夜 ×21 → 月签生成 → 拆信 → 第二循环 → 持久化」全流程，以及引导系统的 24 项专项（含清晰度、滚动跟随、智能选位）。
**零依赖，clone 下来就能跑。**

## 技术实现

**单文件架构。** `index.html` 里装着全部 HTML + CSS + JS，94 KB。

**零依赖 / 零外链。**

- 不依赖任何 CDN、字体、框架、构建工具
- 字体全部走系统字体栈（宋体衬线 + Georgia），**国内打开秒开**，不会卡在字体加载上
- 图标是内嵌的 data-URI SVG

**开箱即用的细节：**

| 能力            | 实现方式                                             |
| --------------- | ---------------------------------------------------- |
| 数据持久化      | `localStorage`，无账号、无服务器、数据不出本机       |
| 离线可用 / PWA  | Web App Manifest 全内联，可"添加到主屏幕"全屏运行    |
| 分享卡片        | Open Graph meta，微信 / 小红书 / QQ 抓取时有预览卡片 |
| 动效            | 纯 CSS transform + transition，骰子用多面体 3D 旋转   |
| 无障碍          | 支持 `prefers-reduced-motion`，动画自动降级          |

**开发中踩过的几个坑**（写在这里给后来人省点时间）：

1. 骰子旋转必须用 `spin * 360 + target` 的整数倍叠加，非整数倍 Y 旋转会把正反面转飞
2. 引导遮罩**绝不能用 `backdrop-filter: blur()`** —— 它会把用户正要看的演示内容一起糊掉。正确做法是「聚光挖洞」：给高亮框一个 `box-shadow: 0 0 0 9999px` 的巨型阴影，框内像素零改动，100% 清晰
3. 任务 id 用 `时间戳 + 随机数` 在同步循环里**必然碰撞**，必须加自增计数器
4. 浮层的定位必须在容器滚动时用 `requestAnimationFrame` 节流重算，否则一滑就"散架"

## 设计说明

界面刻意避开了 AI 生成最常见的视觉套路（紫蓝渐变、玻璃拟态、霓虹光晕），改用：

- **夜墨**底色 `#141109`，接近宣纸浸墨
- **琥珀** `#e9b266` 作火，**青玉** `#8fae97` 作修行，**绯** `#c05a4e` 作天命
- 中文宋体衬线 + 西文 Georgia，朱红印章与月相环作记忆点

整体语气是"安静的仪式感"，不是"活泼的打卡 App"。
